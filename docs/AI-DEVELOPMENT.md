## AI-developed project

**Domyro is an AI-developed open-source software project, built in collaboration with and under the direction, supervision and decision-making authority of @TheRoyalCaptain.**

AI tools are used to help produce source code, technical designs, documentation, test cases and other development work. This is a transparent statement about the project's development process. It is **not** a claim that every file or commit was generated exclusively by AI, or that AI-generated work is automatically correct.

## Responsibilities

- **@TheRoyalCaptain:** defines the project's goals and requirements, directs development, reviews and authorizes official changes and releases, and makes final product and deployment decisions.
- **AI development assistance:** proposes and helps implement code, architecture, documentation, tests and fixes under that direction.
- **Verification:** tests, security reviews, license checks and real-world validation remain necessary. AI assistance by itself is **not** evidence of safety, correctness, professional certification or release readiness.

Domyro's current development builds and proof-of-concept integrations must not be represented as a tested, fully functional home controller before the relevant release gates are passed. The [D-53 installation and safe-update gate](INSTALL-UPGRADE-GATE.md) remains closed until the technical requirements and separate owner deployment approval are satisfied.
